GSC Archive Manager (resources.gsc)

Описание
— Графический инструмент для просмотра и редактирования архивов игровых ресурсов `.gsc` (например, `resources.gsc`/`override.gsc`). Поддерживает:
- Просмотр содержимого архива в виде дерева
- Поиск по имени
- Экспорт отдельных файлов или групп (Batch Export)
- Импорт/замена файлов по выбору или из папки (Batch Replace)
- Создание/сохранение `override.gsc` для безопасной подмены ресурсов без правки оригинала
- Предпросмотр изображений (BMP/PNG/JPG/TGA). Для `.gp/.rlc` отображаются метаданные и доступен экспорт/замена целиком

Примечание: внутриигровый формат `*.gp` имеет сложную компрессию. В текущей версии доступна работа с файлами как с бинарными ресурсами (экспорт/замена). Предпросмотр картинок из `*.gp` будет добавлен отдельным модулем.

Установка и запуск (Windows, PowerShell)
1) Перейдите в папку проекта
```
cd tools/gsc_archive_manager
```
2) Создайте виртуальное окружение и установите зависимости
```
python -m venv .venv
. .venv/Scripts/Activate.ps1
python -m pip install -U pip
pip install -r requirements.txt
```
3) Запуск приложения
```
python -m gsc_manager
```

Использование
- File → Open: выбрать `resources.gsc` или любую `.gsc`
- File → Save As → `override.gsc` в папку игры для подмены ресурсов
- Правый клик по файлу/папке: Export/Replace/Delete
- Batch → Export Folder: сохранить выбранную ветку в каталог
- Batch → Replace From Folder: заменить по совпадению имён (регистр не важен, внутри архива имена в UPPERCASE)

Совместимость
- Инструмент основан на исходном формате проекта (`TGSCarchHDR`/`TGSCarchFAT`, см. `src/Main executable/Arc/GSCtypes.h`).
- Расшифровка при чтении выполняется ключом по умолчанию (EN: 0x78CD → key=~0x78=0x87). Для русской версии возможен ключ 0x4EBA (key=~0x4E=0xB1), переключается в настройках.

Лицензия
- Только для работы с локальными копиями ресурсов пользователя.

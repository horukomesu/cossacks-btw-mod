     12.10. Террейн — перенос швов и смешивания на GPU (без CPU-компоновки) [СДЕЛАНО]
           - Реализация:
             1) Индексный атлас: tiles3.bmp хранится как R8 индексная текстура + отдельная палитра RGBA 256×1; загрузка палитры из ResourceIO. GPU‑индексы включены по умолчанию.
             2) Таблицы переходов: agew_tr4.grd/agew_tr.grd загружаются в R8 256×256; функции trans4/trans8 реализованы в фрагментном шейдере через texelFetch.
             3) Маски A/B/C/D: ms_a/b/c/d.msk декодируются через RLC‑лоадер оригинала и загружаются как R8 64×64 2D‑array; порядок слоёв A→B→C→D соблюдён.
             4) TCES: используются s1/s2/s3 из SectMap; x0/y0 вычисляются по формулам оригинала для соответствующих случаев Prepare1/Prepare2 и паритета.
             5) Шейдер: базовая выборка по baseTileIndex, последовательное применение слоёв A/B/C/D с trans4/trans8 строго как в CPU‑коде Masks.cpp.
             6) Ориентация: учтены оба типа треугольников; для второго типа применяется вертикальный сдвиг y (−31) как в PrepareIntersection2.
             7) Диагностика: логируются отсутствие ресурсов и (де)активация масок; реализация без альтернативных путей — без «фоллбэков» (соответствует Workspace Rules).
             8) Производительность: все текстуры resident; нулевые per‑tile аплоады; один шейдер/VAO, батчинг по VBO. Цель 60 FPS удерживается.
            10) Тесты паритета: визуально совпадает с CPU‑вариантом на тест‑сценах (грани/стыки/края).
           - DoD: визуальное совпадение швов с оригиналом; отсутствие CPU‑компоновки 64×64; удержание 60 FPS.

18. Сохранение/загрузка мира [СДЕЛАТЬ]
    18.1. Сериализация [СДЕЛАТЬ]
        - Версионированный бинарный формат; полная симметрия write/read; секции: карта/сущности/очереди/ресурсы/эффекты/реплей‑метаданные
    18.2. Совместимость [СДЕЛАТЬ]
        - Поддержка чтения оригинальных `.sav` (по мере возможности); маппинг структур; диагностические отчеты несовпадений
    18.3. API [СДЕЛАТЬ]
        - `gameplay::save(path)`, `gameplay::load(path)`; мосты `SFLB_LoadGame/PreSaveGame/SaveGame` (см. п.11.4)

19. HUD/минимэп/оверлеи в игре [СДЕЛАТЬ]
    19.1. Панели и команды [СДЕЛАТЬ]
        - Верхняя панель ресурсов, левая/правая панели юнитов/зданий; кнопки команд/постройки; горячие клавиши
    19.2. Выделение и группы [СДЕЛАТЬ]
        - Рамка выделения, множественный выбор, группы 0–9, портреты/статы; HP‑бары, прогресс‑бары
    19.3. Минимэп [СДЕЛАТЬ]
        - Рендер миникарты, клики/перемещение камеры, отметки событий/врагов; наложение FoW
    19.4. Оверлеи и иконография [СДЕЛАТЬ]
        - Реплей/рейтинг/запись (подключение к п.11.5), курсоры состояний (строить/атаковать/двигаться)

20. Звук в игре [СДЕЛАТЬ]
    20.1. Триггеры SFX [СДЕЛАТЬ]
        - Выстрелы, попадания, смерть, постройка/готово, сбор ресурсов, тревога; пространственная панорама
    20.2. Музыка [СДЕЛАТЬ]
        - Смена треков по состояниям (мир/бой), интеграция с `audio_core::music` и `PlayMode`

21. Интеграция, тесты, производительность [СДЕЛАТЬ]
    21.1. Сквозные сценарии [СДЕЛАТЬ]
        - Загрузка карты → спавн начальных юнитов → базовые команды → бой → сохранение → загрузка → реплей
    21.2. Детерминизм [СДЕЛАТЬ]
        - Повтор кадров по одинаковым входам; прогон фиксированных тест‑реплеев; контрольные хеши по тикам
    21.3. Производительность [СДЕЛАТЬ]
        - 60 FPS на целевых сценах; профайлы «до/после» оптимизаций; отсутствие фризов на сохранение/загрузку
    21.4. DoD для геймплея [СДЕЛАТЬ]
        - Полная совместимость визуала/логики с оригиналом на ключевых сценариях; сохранения/реплеи/мультиплеер работоспособны
